# Hero Background Video Assets

Place your 10-second looping modern motion graphics video files in this folder with the following names:

1. `hero-bg.webm` (WebM format - highly recommended for performance/smaller file size)
2. `hero-bg.mp4` (MP4 format - fallback for broader device/browser compatibility)

## Technical Specifications:
- **Duration:** 10.00 seconds (seamless loop)
- **Resolution:** 1920x1080 (16:9 aspect ratio)
- **Target File Size:** Under 2MB-3MB to ensure fast loading on mobile networks.
- **Audio:** None (remove audio track entirely during export to save size).
